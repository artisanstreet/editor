Artisan Editor by Artisan Street

Artisan Editor is an all-in-one orchestrator for managing agent harnesses.
Run Claude Code, Codex, Cursor, Grok and OpenCode side by side in a single
desktop app, on your own machine or on any host you connect, and keep every
conversation, model and usage limit in one place.


One home for every harness
  Artisan Editor supports Claude Code, Codex, Cursor, Grok and OpenCode,
  along with their subscriptions. Connect your accounts once and switch
  provider at will, even within the same thread.

As many hosts as you need
  Install Artisan Forge on any machine you work on, connect it to Artisan
  Editor in a few clicks, and control all of them from one window.

Smarter controls
  Artisan Editor picks threads back up when they run out of usage, and
  connects and sets up new machines with your credentials automatically.
