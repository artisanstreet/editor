# Bundled native fonts

Spline Sans serves UI, headings, logos and wordmarks. Spline Sans Mono serves code.
Both unmodified variable TrueType fonts support weights 300–700 and are licensed under SIL OFL 1.1.

Corresponding OFL files are in `../licenses/`. Internal family names and fvar axes verified with fontTools 4.63.0.
TrueType bytes are embedded at compile time and registered before the first native window; no runtime font download or system installation is needed.
