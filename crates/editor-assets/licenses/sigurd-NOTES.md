# Sigurd

`fonts/sigurd-400.ttf` is a static weight-400 instance of Sigurd Variable
(Version 2.011, © 2020, 2022 Matthieu Salvaggio, Leon Hugues, all rights
reserved), cut from the web font the Artisan Street dashboard ships
(`web/apps/dashboard/src/lib/assets/fonts/sigurd-variable.woff2`) with
fontTools `instancer` at `wght=400, slnt=0` and renamed to family `Sigurd`.
It draws the sidebar's stacked ARTISAN wordmark. Commercial typeface: a
desktop embedding licence is required before release builds ship it.
