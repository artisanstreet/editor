# JetBrains file icons

This directory contains a curated subset of the SVG file icons from
[`ziishaned/zed-jetbrains-icons`](https://github.com/ziishaned/zed-jetbrains-icons).
The upstream theme packages JetBrains IntelliJ product icons for Zed.

The SVG files retain their original JetBrains copyright headers and are
distributed under the Apache License 2.0:

<https://www.apache.org/licenses/LICENSE-2.0>

Copyright 2000-2024 JetBrains s.r.o. and contributors.

The Svelte fallback is sourced from the existing MIT-licensed
`@selemondev/svgl-svelte` dependency because the upstream JetBrains Zed theme
currently maps Svelte files to its generic text icon.
