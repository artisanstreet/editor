# Codex app-server protocol schema

What Codex itself says it may send: `ServerNotification.json` and
`ServerRequest.json`, generated by Codex 0.162.1. The decoder is checked
against them (`codex::schema_tests`), so a field Codex may leave out or send
as `null` can't become an error in the transcript.

When the installed Codex changes, regenerate them and run the tests:

```sh
codex app-server generate-json-schema --out /tmp/codex-schema
cp /tmp/codex-schema/ServerNotification.json /tmp/codex-schema/ServerRequest.json \
  crates/forge-engines/src/codex/schema/
```
