The [rich block catalog](../skills/artisan-editor/references/blocks.md) is the shared reference for supported `artisan-*` kinds, JSON fields and examples. Keep schema examples there so agent instructions and application documentation use the same catalog.

The client prepares closed fenced JSON as native components. Open fences remain pending; unknown kinds, invalid fields or previews exceeding their resource limits remain readable as source with an explanation. Authored Markdown labels remain stable as metadata arrives.

Media and code references resolve through the owning Forge and thread. The client does not resolve production paths against its own filesystem. Image, audio, model and diagram previews have bounded source, decoded memory and work budgets; copy actions retain their original source where available.
