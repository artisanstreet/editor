# Backend Completion Matrix

Scope: the active objective is the complete backend/core and testing harness described by `artisan-editor-prd.md`. Status is implementation status as of 2026-07-10, not design intent. `missing` means no production implementation exists in this repository; a research or PRD entry is evidence of a gap, not completion.

## Status Legend

- `implemented`: the scoped requirement exists and has a direct verification path.
- `partial`: a narrow slice exists, but the PRD contract is broader or incomplete.
- `missing`: no usable implementation or test seam exists yet.

## Final Completion Audit

- [ ] Every PRD envelope kind, domain command, query, subscription, ACK, heartbeat, stream, and error has an Effect Schema, router, fixture, and compatibility test.
- [ ] Every accepted command is durable, idempotent, correlated, replayable, and projected transactionally; projections rebuild from the ledger.
- [ ] Engine registry and capabilities are explicit; Codex app-server, fallback, normalization, raw capture, and lifecycle behavior pass conformance.
- [ ] Fake process, transcript replay, and opt-in live harnesses pass the shared scenario matrix without paid tests in ordinary CI.
- [ ] AgentOrchestrator owns visible identity, lifecycle, steering, fan-out topology, joins, status, approvals, and artifacts.
- [ ] Terminal/process, files/diffs, Git, previews, and approvals are backend-owned, observable, reviewable, and leak-free.
- [ ] Retention, thread metadata/status, global guidance, provider sync/drift, and project affinity meet their default/lock/recovery rules.
- [ ] Skill and MCP registries enforce scope, compatibility, approval, trust, secrets/auth, lifecycle, sync/drift, and ledgered invocation.
- [ ] Electron control/stream transports negotiate versions, resume cursors, heartbeat, ACK, bounded buffering, and transport equivalence.
- [ ] Temporary workspace/Git/SQLite integration, property/state-machine, load, architecture-boundary, and surface normalization suites pass.
- [ ] A clean checkout passes formatting, lint, typecheck, unit, conformance, integration, property, and release gates with no unapproved live dependency.
