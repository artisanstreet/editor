# Backend Completion Matrix

Scope: the active objective is the complete backend/core and testing harness described by `artisan-editor-prd.md`. Status is implementation status as of 2026-07-18, not design intent. Codex CLI is the sole production engine during prototyping; future engine adapters are intentionally deferred. `missing` means no production implementation exists in this repository; a research or PRD entry is evidence of a gap, not completion.

Verification snapshot (2026-07-18): full `pnpm run validate` passes formatting, lint, TypeScript, the production frontend build, 106 test files, and 898 passing tests plus two intentional skips. The M1 focused protocol/rebuild/transaction/erasure gate passes 6 files and 33 tests; the evidence/rebuild/transaction/erasure regression batch passes 19 tests. Windows keeps the unchanged 15-second per-test timeout and runs Vitest files through one worker so concurrent PowerShell ACL operations and Codex process hosts cannot create false timeout cascades; non-Windows platforms retain Vitest's default parallelism.

## Status Legend

- `implemented`: the scoped requirement exists and has a direct verification path.
- `partial`: a narrow slice exists, but the PRD contract is broader or incomplete.
- `missing`: no usable implementation or test seam exists yet.
