# Backend Completion Matrix

Scope: the active objective is the complete backend/core and testing harness described by `artisan-editor-prd.md`. Status is implementation status as of 2026-07-13, not design intent. `missing` means no production implementation exists in this repository; a research or PRD entry is evidence of a gap, not completion.

## Status Legend

- `implemented`: the scoped requirement exists and has a direct verification path.
- `partial`: a narrow slice exists, but the PRD contract is broader or incomplete.
- `missing`: no usable implementation or test seam exists yet.
